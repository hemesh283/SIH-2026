# frontend-android/

Your friend's existing Android Studio project goes here (data-collection app /
on-device demo client). Drop the Android Studio project folder in directly —
`app/`, `gradle/`, `build.gradle`, etc. — so it sits alongside the rest of the
pipeline in one repo.

If a live dashboard is also needed (not just the Android app), consider a
React + Vite + Recharts web dashboard living under `frontend-web/` at the repo
root instead of inside this folder, per the dossier's tech stack (Section 6).
